about=View 360° panoramic photos (photospheres) linked from a layer's attributes, directly inside QGIS, with a live direction sector drawn on the map. Built on the Pannellum and Three.js libraries.

    Panorama Viewer NG is the next generation of the "Panorama Viewer" plugin by Pavel Pereverzev
    (https://github.com/pavelpereverzev/panorama_viewer), ported to QGIS 4 / Qt6 and maintained by Theo Gatsios.

    Compatibility:
    • QGIS 3.x (Qt5): uses QtWebKit, as the original plugin.
    • QGIS 4.x (Qt6): uses QtWebEngine. The Qt WebEngine Python bindings must be installed
      (e.g. PyQt6-WebEngine / python3-pyqt6.qtwebengine). Without them, panoramas open
      in the system web browser instead.

    Quick guide:
    1. Open a layer of any geometry type.
    2. Add a text field and fill it with direct links to 360° photos (local paths or web URLs).
    3. Open the plugin, select the "Layer" and "Field" with the image links.
    4. Select a feature on the map and click "View panorama".

    Options:
    • Auto-update view: loads panoramas automatically on selection.
    • Show directions: draws a direction sector at the panorama location.
    • Angle field: sets the initial view angle from a layer field.
    • Viewer: Pannellum, Three.js, or Canvas, which needs no WebGL (used automatically when WebGL is unavailable).
    • Hidden buttons (bottom right of the viewer, on hover): open in browser, maximise viewer.

changelog=1.3 (first release of Panorama Viewer NG):
    - QGIS 4.x / Qt6 support via a QtWebEngine backend; QtWebKit still used on QGIS 3.x / Qt5
    - System-browser fallback when no embedded web engine is available
    - New "Canvas (no WebGL)" viewer, selected automatically when WebGL is unavailable
    - Support for smb:// and file:// panorama links, with clear error messages
    - Panorama image served with no-cache headers (no stale images between features)
    - Fixed Three.js viewer not loading images on case-sensitive file systems
    - More robust downloads (missing Content-Length) and plugin unload
    - New icon
    Based on Panorama Viewer 1.2 by Pavel Pereverzev.
